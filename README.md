# Sistema de Gestión de Estudiantes (SGE) básico

Proyecto académico desarrollado en Java para la materia **Algoritmos y Programación**.  
El sistema permite:
- Agregar estudiantes
- Mostrar lista completa
- Buscar estudiante por ID
- Salir del sistema

## Tecnologías utilizadas
- Lenguaje: Java
- IDE recomendado: IntelliJ IDEA / Eclipse / NetBeans
- Control de versiones: GitHub
